# 当前机器人最终训练目标与验收范围

唯一训练资产：`assets/wheel_leg_train.urdf`。部署接口保持25D observation、125D history、
6D action，腿position/轮velocity混合PD。禁用隐藏LQR、真实速度替换、命令offset或额外补偿。

最终目标不是某个阶段reward变高，而是同一个可部署策略具备：

| 能力 | 最终要求 | 当前证据 |
|---|---|---|
| 零命令 | 稳定停车，vx MAE≤0.05m/s、绝对yaw≤0.10rad/s | 旧低速model100通过 |
| 正反向平移 | 0/±0.5/±1/±2/±3/±4m/s均可跟踪，运动vx MAE≤0.10 | 尚未有同一模型完整通过±1及低速回归 |
| 原地自转 | ±0.5/±1/±2/±3/±4rad/s，同时平移接近零 | 未完成系统验收 |
| 自然转弯 | 正向/反向行驶中的左右转，先低速再扩大范围 | 未完成 |
| 顺滑切换 | 加减速、停车、前后反向、直行/转向切换 | 未完成响应延迟/超调验收 |
| 稳定性 | 无跌倒/非轮触地、各轮接触≥99%、高度误差≤0.03m、无持续力矩饱和 | 必须逐checkpoint核查 |
| 部署一致性 | 选中checkpoint与ONNX数值一致，后续进入独立闭链sim2sim | 仅低速model100做过ONNX检查 |

固定命令验收最少3个seed×每命令16env、25秒、5秒warmup，deterministic，
level1随机化。逐seed逐命令判定，不能只用跨seed均值。数值门槛延续既有统一验收，
不因模型接近门槛就事后放宽。timeout和失败分别记录。

自转和转弯还需扩展验收器，正确记录actual vx/yaw与两侧接触；不能只看yaw符号。
高速4m/s与原地4rad/s分别达标不意味着必须同时命令4m/s+4rad/s；转弯组合应明确
记录具体vx/yaw，评估可实现的横向加速度和姿态，不以危险的同时极值替代自然转弯目标。

顺滑性需单独记录上升/下降时间、超调、反向切换轨迹以及动作变化，静态网格通过
不代表顺滑。最终同一个策略必须回归全部已学阶段，不能拼接多checkpoint冒充完成。

当前实验：`EXPLORE_STOP_RETENTION`，job
`plane/outputs/explore_stop_retention_20260919_123152`，从探索分支model500继续，
仅把zero采样提高到40%，保持±0.5/±1各15%。该源在±1三seed通过，但zero与+.5
尚不全过；它是实验起点，不是阶段晋级。结果以status.json/acceptance.json为准。

每轮500iteration和独立验收后更新结论。阶段失败时保留已通过基线；本文件不授予
更改资产、电机、物理接口或降低门槛的许可。最终完整目标仍处于未完成状态。
